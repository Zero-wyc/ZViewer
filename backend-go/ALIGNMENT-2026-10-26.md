## 后续 PR 必须说明的网易云故障根因

Go 迁移把原 Node 后端进程内启动的 NCM API 外部化，但 GUI 分发只包含 Go 后端、网页、LiveKit、CLI 等组件，未同时交付或启动网易云服务。默认 `127.0.0.1:36530` 无服务时，扫码 key 接口返回 503 `NCM_UNAVAILABLE`；网页只取字段，错误状态下仍显示生成动画。这是 GUI 交付和启动链路遗漏，不能只归因于第三方接口不稳定。

GUI 打包现在包含 `runtime/ncm/`：Node、锁定到 4.41.1 的 NCM API、依赖和启动器。源码保留依赖锁，生成物不入 Git。后端未显式配置 `NCM_API_BASE` 且存在随包组件时启动私有服务，独立回环端口与 `config/ncm-cache` 匿名缓存；正式凭证仍按用户存入原数据库。后端取消时关闭组件，异常退出后 3 秒重启，启动器检查父进程存活；GUI 的进程监管负责整个进程树。显式外部服务配置优先，源码/容器仍可使用原部署方式。

网页与移动音乐请求保留 HTTP/业务错误，503 显示具体提示与重试，不清 App 或音乐登录信息。内容页可重新加载；扫码失败停止动画、提供重新获取，轮询有并发、取消与有限失败保护。音乐上游 401/403 不刷新 ZViewer 登录。

## S01：完整播放快照

`PlaybackMetadata` 保留 `playsvideoEnabled / hostCliEnabled / epId / seasonId / seasonTitle / preview`。可选布尔用指针，false 不丢失。查询、心跳和恢复继续共用 Playback。

新增可空 `playback_states.metadata` JSON 列。新库包含该列，旧库通过明确幂等迁移只加此列，不重建旧行；旧快照对应字段为空，新快照落盘后可跨重启恢复。换源会清旧元数据。回退到旧 Node synchronize 可能移除新增列，回退后的扩展元数据持久性未保证。

## S02：B站代房主解析准入

带 movieId 先校验影片读取准入，之后才展开链接和读房主凭证。非法/空 ID 返回 400，影片不存在 404，未入房或已结束会话 403；保留现行 root/持久房主对关闭房间的管理权限。

资源限定为记录中的 BV/av 或番剧 ep/ss；季链接解析其他分集时向 B站查询权威分集归属，不信任可编辑 pages 扩大范围。无 movieId 使用请求者凭证，不静默借用其他身份。

## 双端对齐

- 统一 NCM 不可用提示、重试和扫码生命周期。
- 挂载直链保留 status/code/message；失败停止并提示，不回退旧签名 URL 或服务器代理。挂载 `AUTH_FAILED` 不刷新 App 登录。
- 播放广播补番剧字段，观众优先用影片 DTO 明确策略。
- 影片转预览时不执行 null 选择清理；取消旧下载，迟到完成不继续播放或广播；删片清完整源快照。
- 原生 PGC MP4 默认请求 64，保留手动/恢复低档；本机 UGC/DASH 保留账号和设备策略，更新 MP4 说明。
- 补管理设置可选类型；音量均衡为可选本地功能，本轮未移植，未新增后台管理页面或修改 iOS。
