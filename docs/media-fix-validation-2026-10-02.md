# 浏览器转码与 PGS 字幕修复验证（2026-10-02）

## 修复内容

- “浏览器转码引擎”开启时，playsvideo 原来的 MKV 快速索引把所有 CueTrack 的时间都当成视频关键帧。字幕 Cue 触发切段时，视频回退到前一关键帧，音频从字幕 Cue 时间开始，造成秒级错位。现在以选中视频轨的 TrackNumber 过滤 CueTrackPositions；无法获得视频索引时回退实际关键帧扫描。Worker 与 Source 两种入口都已修复。
- 每段 AC3 等音频单独转 AAC 时，移除 FFmpeg AAC 编码器的 1024 样本 priming 帧，使用 ADTS 声明的采样率计算时间戳，并限制编码尾部填充不越过分段范围。
- 新增 PGS 位图解码与 PNG 字幕渲染，支持调色板、RLE、ODS 分片、多个对象、裁剪和清屏；保持原始画布位置与 PCS 时间轴。PNG 数据可随既有字幕状态同步给观众。位图字幕字号取决于原始图像，现有文字字体设置只影响文字字幕。
- 修正 MKV ContentEncodings/ContentEncoding 元素 ID、压缩算法编号和语言元素 ID，支持 zlib 与 header stripping。PGS 按文件顺序读取，避免并行乱序破坏调色板与对象状态；大文件后台逐批加载。
- 修正字幕切换后的取消和旧结果广播，并在字幕数据替换时刷新当前显示。添加服务器文件根目录后立即失效缓存。
- playsvideo 修改保存在 `patches/playsvideo+0.4.7.patch`，重新安装依赖时由现有 postinstall 自动应用。

## 实测

使用独立配置启动本地服务器，测试媒体以只读根目录挂载。真实 Chrome 浏览器验证了引擎测试页面和后端托管的正式前端页面。

| 媒体 | 验证结果 |
| --- | --- |
| 高速文件 Resident Evil.2026.1080p.SDR.24fps.AVC.AC3 2.0.mkv | H.264/AC3/PGS；0、4、640、1124、3600、5100 秒附近的分段音视频起始时间差为 0 ms；浏览器正向/反向跳转、分段连续加载无致命错误。 |
| 与你相恋到生命尽头 - S01E01 - 第1集.mkv | H.264/AAC/ASS；修复前约 668、1148 秒处出现字幕 Cue 切段、视频回退接近 2 秒；修复后视频分段起点与计划一致。6 处采样中音视频首包差为 0–15 ms（保留源 AAC 包边界差异）。正式页面跳转至 640 秒后正常播放。 |

完整 PGS 提取结果：941 个位图显示项，序列化大小 17,686,915 字节；首条 65.208–66.000 秒，最后结束时间 5140.417 秒。所有显示项的起止时间、数量和序列化大小与 FFmpeg 从同一 MKV 复制导出的 SUP 经同一解码器解码的结果完全一致。正式页面 65.5 秒处已截图确认原位字幕显示。

1124–1128 秒源音频与修复后转码音频的 PCM 相关性：0.9997478，最佳时间偏移 0 样本（0 ms）。这项检查验证音频内容时间，不仅检查封装时间戳。数值分段/PCM检查使用本机 FFmpeg；实际浏览器播放使用 playsvideo 自带音频 WASM。
