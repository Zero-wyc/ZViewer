# 一起听默认音量与私人漫游续播

## 默认音量

- 权限管理 / 基础设置新增「房间默认音量」，使用现有 Material 主题 Slider，范围 0～100、步长 1。
- 点击滑条右上方百分比可输入整数，Enter 或失焦确认，Escape 取消；越界、小数或非数字不会修改设置。
- `SystemSettings.roomDefaultMusicVolume` 以整数百分比保存，初始值 50。数据库自动同步为旧数据库补充默认列，公开设置接口下发该非敏感字段。
- 一起听未保存过有效本地音量时使用服务器默认值；保留 `zc-music-volume` 中用户手动设置的音量，包括静音。音量不参与房主/观众同步。
- 设置异步返回时更新未手动调节的播放器；管理员修改默认值不会覆盖已经保存的用户偏好。

## 私人漫游续播

原先 FM 候选仅存在页面中，点击播放只把当前曲目加入房间队列。自然结束时播放器按房间队列推进，只有一首时再次播放自身。

现在 FM 候选、历史和模式由房间播放器共享的会话保存。房主启动 FM 后，自然结束或点击播放器「下一首」会选择新候选，等待 `music:queue-upsert` 成功确认，再播放并广播同步状态；候选不足时自动补拉，切换音乐页面后仍可续播。明确选择「单曲循环」时保留该模式的行为。

仅房主推进 FM，观众等待房主同步；正常队列、B站推荐续播仍使用原有路径。切换到普通歌曲、B站插播、离开房间或断连会停用 FM 会话。模式切换、用户操作和离房会使旧异步响应失效，避免过期请求再次启动播放。入队失败保留候选并提示错误。

## 验证

- `npm run build`：前后端构建。
- `npm test -w frontend`：已有音乐工具测试。
- `npm run test:music`：初始音量、有效本地偏好、FM 请求去重、模式/场景切换、连续推进和耗尽补拉、入队确认与失败、旧会话取消。
- 修改文件 ESLint 检查。
- 本地独立数据库页面验收：滑条与数字编辑、0/100 边界、拒绝小数/越界、保存后刷新、公开接口和后端校验；一次播放操作后实际短音频自然结束，连续播放 6 首，中途切换页面仍继续，检查房间队列已持久化。

页面验收使用模拟网易云登录、候选与短音频，房间创建、入队、配置保存和数据库均由本地真实服务端处理；不等同于真实网易云账号、VIP 音源和网络条件下的验收。
